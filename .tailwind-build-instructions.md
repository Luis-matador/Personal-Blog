# Instrucciones para construir Tailwind CSS

## Cada vez que agregues nuevas clases de Tailwind a tus archivos PHP, debes ejecutar:

```bash
npm run build
```

Este comando regenerará el archivo `public/css/style.css` con todos los estilos de Tailwind que estés usando.

## Durante el desarrollo (modo watch):

Si quieres que Tailwind se regenere automáticamente cada vez que hagas cambios:

```bash
npm run watch
```

Esto dejará Tailwind ejecutándose en segundo plano y regenerará el CSS automáticamente cuando detecte cambios.

## Notas importantes:

- **Tailwind CSS v4** solo incluye los estilos que realmente estás usando en tus archivos
- Cada vez que agregues nuevas clases CSS de Tailwind, necesitas ejecutar `npm run build`
- Los archivos que Tailwind escanea están configurados en `tailwind.config.js` (carpetas `views`, `public`, `controllers`)
- El archivo fuente es `src/input.css` y el archivo de salida es `public/css/style.css`

## Solución de problemas:

Si algunos estilos no aparecen:
1. Verifica que las clases estén escritas correctamente en tus archivos PHP
2. Ejecuta `npm run build` nuevamente
3. Recarga la página en el navegador (Ctrl+F5 para limpiar caché)
